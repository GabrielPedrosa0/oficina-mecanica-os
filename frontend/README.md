# Frontend — Oficina Mecânica

React 19 + Vite, CSS puro com as variáveis do Figma, `react-router-dom` e `lucide-react`.

- Guia completo: [`../docs/guia_frontend.md`](../docs/guia_frontend.md)
- `npm run dev` · `npm run build` · `npm run lint` · `npm run formatar`
- Em desenvolvimento, `/api` é repassado para o FastAPI em `http://127.0.0.1:8000` (ver `vite.config.js`).
